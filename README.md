# 躲猫猫大挑战 🐱🐭

新生破冰活动 - 躲猫猫游戏管理平台

## 功能特性

### 玩家端
- 姓名+学号登录
- 身份查看（猫/鼠）
- 队伍查看与成员信息
- 个人信息管理（微信号）
- 二维码身份码展示
- 猫扫码抓捕鼠
- 积分与排行榜（个人/团队）

### 工作人员端
- 账号密码登录
- 游戏创建与管理（开始/暂停/结束）
- 玩家管理与搜索
- 扫码指定猫（主动申请）
- 身份自动分配（按比例随机）
- 自动分队
- 扫码工作台（查看玩家详情）
- 复活管理（小游戏挑战）
- 小游戏管理（创建/配置/排行榜/结算奖励）
- 排行榜查看（个人/团队，按角色筛选）
- 积分手动调整

## 游戏规则

1. **身份分配**: 猫鼠比例约 1:10，工作人员可预先指定部分猫
2. **抓捕**: 猫扫描鼠的二维码获得积分
3. **死亡**: 鼠被扫描后进入死亡状态
4. **复活**: 工作人员发起复活小游戏，通过后鼠复活（带保护时间）
5. **积分**: 抓捕积分 + 小游戏积分 + 生存积分
6. **排行榜**: 个人排行榜 + 团队排行榜

## 快速开始

### 安装依赖

```bash
pip install -r requirements.txt
```

### 启动服务

```bash
python run.py
```

服务将在 http://localhost:8000 启动

### 默认账号

- **工作人员**: admin / admin123
- **玩家**: 使用姓名+学号登录

## 页面入口

- 首页: http://localhost:8000/
- 玩家登录: http://localhost:8000/player/login
- 工作人员登录: http://localhost:8000/staff/login

## 技术栈

- **后端**: FastAPI + SQLAlchemy + SQLite
- **前端**: 原生 HTML/CSS/JavaScript
- **认证**: JWT
